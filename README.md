# Awesome Markdown Resumes [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of tools, templates, examples, and resources for creating beautiful resumes using Markdown.

Markdown resumes combine the simplicity of plain text with the power of version control, making it easy to maintain, update, and export your professional resume in multiple formats.

## Online Tools & Generators

- **[MarkdownResume.app](https://markdownresume.app)** - Modern, feature-rich online editor for creating professional resumes from Markdown. Real-time preview, multiple export formats, and beautiful templates.
- [JobEmerge](https://www.jobemerge.work) - AI career copilot with a Markdown resume editor and PDF, Word, PNG, and Markdown export.
- [Resume.md](https://resume.md) - Simple online Markdown resume builder with PDF export.
- [Resumey.Pro](https://resumey.pro) - Online resume builder supporting Markdown input.

## Desktop Applications

- [Resume Generator](https://github.com/soulehshaikh99/resume-generator) - Electron-based desktop app for creating resumes from Markdown.
- [Typora](https://typora.io) - Markdown editor that can be used for resume creation with custom CSS.

## Templates

## Why Markdown for Resumes?

- ✅ **Version Control** - Track changes with Git, maintain multiple versions easily
- ✅ **Plain Text** - No vendor lock-in, works with any text editor
- ✅ **Focus on Content** - Separate content from presentation
- ✅ **Multiple Formats** - Export to PDF, HTML, DOCX, and more
- ✅ **Easy Updates** - Quick edits without fighting with formatting
- ✅ **Readable** - Human-readable source that's easy to review
